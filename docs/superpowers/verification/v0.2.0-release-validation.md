Rust 使用本机 1.93 工具链和独立 `CARGO_TARGET_DIR`；三平台发布工作流使用 1.97.1，仍需独立通过。首轮默认输出目录遇到 Windows 文件占用，切换独立目录后通过，没有终止用户程序。Windows 的 scripts/deploy 测试出现 POSIX 权限、符号链接、路径假设失败，不记为通过；scripts 已在 Linux 重跑通过。普通 Windows `git archive` 也受 `core.autocrlf` 影响，验证导出使用命令级 `-c core.autocrlf=false`，未修改宿主 Git 配置。

SSE 脱敏证据保留原始换行及最后事件的空行分隔符；`.gitattributes` 对该类证据保留字节，并允许 CRLF 和末尾空行。
